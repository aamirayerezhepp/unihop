# UniHop

Платформа для школьников из СНГ, которые поступают в зарубежные вузы. Интерфейс на русском и казахском (переключатель RU / KZ).

- **До теста:** лендинг с тестом «Узнай шансы» (8 вопросов) и результат «Мечта / Реально / Надёжно».
- **Кабинет после теста:** главная, план по месяцам, мой список вузов, документы и профиль, стипендии, поддержка, чат с Қояном, уведомления.

React 18 + Vite 5. Вход через Google и хранение данных — Firebase (включается ключами в `.env.local`, пошагово — в [GOOGLE-SETUP.md](GOOGLE-SETUP.md)). Без ключей сайт работает как раньше: данные хранятся в браузере.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Откроется на http://localhost:5173. Живой чат с Қояном и сохранение в аккаунте работают только внутри Claude-артефакта; локально чат отвечает на три готовых вопроса, а данные хранятся в браузере.

## Сборка

```bash
npm run build
```

```bash
npm run artifact
```

Вторая команда делает `artifact/orientir.html` — одну страницу со встроенными CSS и JS для публикации как Claude-артефакт (картинки Қояна публикуются рядом, в `orientir-assets/`).

## Структура

- `src/App.jsx` — экраны по адресу (`#plan`, `#list`, `#docs`…)
- `src/state/AppState.jsx` — данные ученика, язык, тест, чат, сохранение
- `src/i18n/strings.js` — все тексты интерфейса на русском и казахском
- `src/views/` — экраны
- `src/components/Shell.jsx` — оболочки: публичная (жёлтая шапка) и кабинет (боковое меню / нижние вкладки)
- `src/data/` — вопросы теста, вузы, шаги плана, стипендии, документы, телефоны доверия; каждый текст в виде `{ru, kz}`
- `src/lib/logic.js` — подбор стран и вузов, план, дедлайны, напоминания, инструкции для Қояна
- `public/orientir-assets/` — позы Қояна

Документы: сайт хранит только отметки «готово / в работе / не хватает», сами файлы не загружаются.
Уведомления: пока только внутри сайта; Telegram и email не подключены.
Данные о сроках и стипендиях проверены в ноябре 2026 и обновляются в `src/data/`.
